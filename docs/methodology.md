# Research methodology

1. **Question:** formulate one falsifiable security property.
2. **Source:** cite primary documentation and record version applicability.
3. **Model:** define assets, attacker capabilities and trust boundaries.
4. **Experiment:** isolate target, save exact commands and code revision.
5. **Observation:** distinguish actual measurements from assumptions.
6. **Regression:** add automated positive, negative and boundary tests.
7. **Report:** state impact, reproduction, limitations, and remediation.
8. **Disclosure:** report genuine vendor issues privately before publication.

Evidence labels: `OFFICIAL`, `THIRD_PARTY`, `OBSERVED`, `HYPOTHESIS`.
