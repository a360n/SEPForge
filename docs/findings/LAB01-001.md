# LAB01-001 — Stack-Based Buffer Overflow

## Classification
- CWE-121: Stack-Based Buffer Overflow
- Component: Lab 01 / unsafe_copy.c
- Status: Confirmed in intentionally vulnerable lab
- Platform: Apple Silicon macOS (ARM64)

## Root Cause
The vulnerable function copies a 15-byte string
into an 8-byte stack buffer without validating capacity.

## Evidence
AddressSanitizer reported:
- stack-buffer-overflow
- WRITE of size 15
- unsafe_copy.c:8
- Buffer boundaries: stack offsets [32, 40)

## Remediation
Validate the source length against destination capacity
before copying, including the null terminator.

## Validation
- Unsafe sample: ASan detects stack-buffer-overflow.
- Safe sample: ASan reports no error for tested inputs.
- Boundary tests: 4/4 passed.

## Scope
This is an educational vulnerability in SEPForge code.
It is not a vulnerability in Apple SEP or macOS.
